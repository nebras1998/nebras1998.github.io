# قائمة تدشين الإنتاج — مختبرات الشمال (LabSystem-WPF)

> مرجع قابل للتأشير لفريق الإنتاج. بنود بيئة/استضافة تتطلب وصولاً لبيئة فعلية
> ولا يمكن تنفيذها من داخل المستودع. المصدر: `docs/SECURITY-AUDIT.md`.
> كل ما يمكن تنفيذه كوداً نُفِّذ داخل المستودع وموثّق في مواقعها.

## 1. Appwrite Console

- [ ] راجع صلاحيات كل مجموعة + بكرة التخزين مقابل `docs/PERMISSIONS.md` — لا يبقى
      أي `read("any")`/`write("any")` في أي مجموعة أو بكرة (المطلوب: `users` فقط).
- [ ] اضبط `allowed domains` = نطاق الاستضافة الفعلي فقط (المتصفح) و`server integrated login`.
- [ ] فعِّل 2FA على حسابات لوحة الـ Console.
- [ ] دوِّر `APPWRITE_API_KEY` — أنشئ مفتاحاً جديداً وأبطل القديم (المفتاح الوحيد في
      `.env` غير المتعقَّب، ولا يُنشر في المستودع).
- [ ] راجع مدة صلاحية الجلسات (الافتراضي 30 يوماً؛ أقصر إن أمكن).

## 2. الاستضافة / reverse proxy

- [ ] Reverse proxy حقيقي يضبط `X-Forwarded-For` ويتجاهل هيدر العميل — شرط ضروري
      لدقة `src/lib/rate-limit.ts` (المفتاح الحالي IP + جلسة).
- [ ] TLS فعلي خلف نهاية الإنهاء حتى يعمل `Strict-Transport-Security` (يفعَّل تلقائياً
      في وضع الإنتاج عبر `next.config.ts`).
- [ ] لا تُعرِّض المنفذ 3000 مباشرة؛ اربط التطبيق بالـ proxy فقط.
- [ ] اضبط `APP_PUBLIC_URL` (بيئة الإنتاج) — يُستخدم لرابط QR في التقارير ومسارات المشاركة.

## 3. البيانات / النسخ الاحتياطي

- [ ] نفِّذ تجربة **استعادة** كاملة واحدة على بيئة Staging من zip التصدير
      (`GET /api/admin/backup/export`) تحققاً من سلامة الدورة قبل الإطلاق.
- [ ] جدولة نسخ احتياطي تلقائي أسبوعي على الأقل (استدعاء مسار التصدير بنفس مفتاح الجلسة/الدور).

## 4. تشغيل خادم التطبيق

- [ ] قبل كل إطلاق: `npm ci` ثم `npm run build` على بيئة الإنتاج نفسها.
- [ ] تحقق أن خطوط IBM Plex محلية (`next/font/local`) وصفحة الحجوزات تستخدم dayjs
      (لا اعتماد على شبكة خارجية وقت البناء).
- [ ] على Debian/Ubuntu، لا تعطِّل sandbox الخاصة بـ chromium في مسار PDF
      (`puppeteer.launch`) ما دامت متاحة.
- [ ] راقب الذاكرة: كل طلب PDF يُطلِق متصفحاً؛ اضبط حدود الـ rate-limit في
      `src/app/api/reports/[id]/pdf/route.ts` حسب الطاقة المتاحة.

## 5. التحقق النهائي قبل الإعلان

- [ ] `npx tsc --noEmit` · `npx eslint .` (0 أخطاء/تحذيرات) · `npm test` · `npm run build` نظيفة.
- [ ] k6: `01` (صفحات عامة)، `03` (rate-limit على verify)، `04` (مصادقة) مع `SESSION_COOKIE`.
- [ ] جولة يدوية: تسجيل دخول → لوحة (إحصاءات/تقارير/موارد بشرية) → PDF → نسخ احتياطي
      → حجز أونلاين → QR تحقق → تقويم الحجوزات بالعربية.

## ملاحظات تشغيل مستقبلية

- `rate-limit.ts` يعتمد عدّاداً في الذاكرة لكل عملية. عند أي تشغيل **متعدد العمليات/المثيلات**
  انقل التخزين إلى مخزن مشترك (Redis/DB) قبل الاعتماد على الحدود عبر المثيلات.
